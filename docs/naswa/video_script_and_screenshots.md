# NASWA nomination: video script and suggested screenshots

**Draft | ~2:30 runtime | Companion to
[nomination_draft.md](nomination_draft.md)**

## Capture rules (public posting)

- NASWA posts nominations publicly. **Record and screenshot only the synthetic
  demo workbook.** Although the production workflow runs on live veteran data in
  the JVSG SharePoint site, never show live data, real names, SIDs, case notes,
  or SharePoint URLs/tenant details on screen.
- Check browser tabs, file paths, user names, and notifications before recording.
- Leadership review of the final cut is required before submission.

## Suggested screenshots (all synthetic)

1. **Dashboard overview** — cohort and office summary. Caption: "Management
   summary view (synthetic data)."
2. **Staff follow-up drill-down** — filtered list with freshness indicators.
   Caption: "Follow-up queue with data-freshness status (synthetic data)."
3. **Referral brief** — fixed-template brief marked for qualified staff review.
   Caption: "Fixed-template brief; no automated referral (synthetic data)."
4. **Data-flow diagram** — export → validation → ETL → dashboard → staff review,
   with "human review" and "GeoSol = system of record" labels.
5. **Validation result** — a refresh showing input checks passing or flagging a
   problem file. Caption: "Inputs are validated before each refresh."
6. **Safeguards slide** (optional) — synthetic-only development and testing,
   live data confined to the access-controlled JVSG SharePoint site, human
   review of all decisions.
